# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/EmmanuelARB/pi-mistral-subscription/security/advisories/new),
not in a public issue. Include what is affected, how to reproduce it and the impact you expect.

You will get an acknowledgement within 7 days. Fixes are prepared in a private security advisory,
shipped, and then the advisory is published with credit to the reporter, unless you prefer not to be named.

## Supported versions

Supported: `main` and the latest release tag. Fixes land on `main` and ship in the next release
tag. If you pinned a tag, reinstall with the newer tag to get a fix.

Never include real API keys, OAuth credentials or Pi auth files in a report; describe them or use placeholders.
